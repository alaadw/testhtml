Introduction to Semantic HTML

Semantic HTML elements clearly describe their meaning in a human- and machine-readable way. They provide structure and meaning to your content, making it more accessible and SEO-friendly.

Common Semantic Elements

Page Structure Elements

  • <header> - Contains introductory content or navigation links
  • <nav> - Contains navigation links
  • <main> - Contains the main content of the page
  • <article> - Contains independent, self-contained content
  • <section> - Groups related content together
  • <aside> - Contains content aside from the main content (sidebar)
  • <footer> - Contains footer information

Content Elements

  • <figure> - Groups media content with caption
  • <figcaption> - Provides caption for figure
  • <time> - Represents a specific time
  • <address> - Contact information
  • <details> - Collapsible content
  • <summary> - Summary/heading for details element

Quick Tips

Remember: Semantic elements don't change the appearance of your page by default - they provide meaning!

Best Practices:

  1. Use semantic elements instead of generic divs when possible
  2. Each page should have only one <main> element
  3. Use <article> for content that could stand alone
  4. Use <section> to group related content
  5. Always include proper headings (h1, h2, etc.)
