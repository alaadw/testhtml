Lesson 4: Images and Media

🎯 What You'll Learn

  • How to add images to your web pages
  • Image attributes and accessibility
  • Responsive images for different screen sizes
  • Working with different image formats
  • Adding videos and audio to your pages
  • Best practices for web media

🖼️ Basic Image Syntax

Images are added using the <img> element. This is a "self-closing" tag:

<img src="photo.jpg" alt="A beautiful sunset over the mountains">
Required Attributes:
• src = source (path to the image file)
• alt = alternative text (describes the image for screen readers and if image fails to load)

🏷️ Image Attributes

Essential Attributes

<img src="logo.png" alt="Company Logo" width="200" height="100" title="Our awesome logo">
Demo Image
(Company Logo)

Attribute Explanations

  • src: The file path or URL to the image
  • alt: Text description (crucial for accessibility!)
  • width/height: Dimensions in pixels
  • title: Tooltip text when you hover over the image

📁 Image File Paths

Relative Paths

<!-- Same folder --> <img src="photo.jpg" alt="Photo"> <!-- Images subfolder --> <img src="images/photo.jpg" alt="Photo"> <!-- Parent folder --> <img src="../photo.jpg" alt="Photo"> <!-- Multiple folders --> <img src="assets/images/gallery/photo.jpg" alt="Photo">

Absolute Paths and URLs

<!-- From website root --> <img src="/images/logo.png" alt="Logo"> <!-- External URL --> <img src="https://example.com/image.jpg" alt="External image"> <!-- Data URL (base64 encoded) --> <img src="data:image/png;base64,iVBORw0KGgoAAAANS..." alt="Inline image">

🎭 Image Formats

Format Best For Pros Cons
JPEG (.jpg) Photos, complex images Small file size, good quality No transparency, lossy compression
PNG (.png) Graphics, logos, transparency Transparency support, lossless Larger file size
GIF (.gif) Simple animations, logos Animation support, small size Limited colors (256)
SVG (.svg) Icons, simple graphics Scalable, small size, CSS styleable Not good for photos
WebP (.webp) Modern web images Excellent compression, all features Limited browser support (older browsers)

📱 Responsive Images

CSS-based Responsive Images

<style> .responsive-img { max-width: 100%; height: auto; } </style> <img src="large-photo.jpg" alt="Responsive photo" class="responsive-img">

HTML Responsive Images (srcset)

<img src="photo-800.jpg" srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1200.jpg 1200w" sizes="(max-width: 400px) 400px, (max-width: 800px) 800px, 1200px" alt="Responsive photo with multiple sizes">

Picture Element for Art Direction

<picture> <source media="(max-width: 600px)" srcset="mobile-image.jpg"> <source media="(max-width: 1200px)" srcset="tablet-image.jpg"> <img src="desktop-image.jpg" alt="Responsive image with art direction"> </picture>

🎯 Accessibility and SEO

Writing Good Alt Text

<!-- Good alt text --> <img src="cat.jpg" alt="Orange tabby cat sleeping on a blue couch"> <!-- Bad alt text --> <img src="cat.jpg" alt="Cat"> <img src="cat.jpg" alt="IMG_1234.jpg"> <img src="cat.jpg" alt="Picture of cat"> <!-- Decorative images (empty alt) --> <img src="decoration.png" alt="" role="presentation">

Figure and Figcaption

<figure> <img src="chart.png" alt="Sales growth chart showing 20% increase"> <figcaption> Sales increased by 20% in Q3 2024 compared to Q2 2024 </figcaption> </figure>

🎬 Video Elements

Basic Video

<video controls width="400"> <source src="movie.mp4" type="video/mp4"> <source src="movie.webm" type="video/webm"> Your browser does not support the video tag. </video>

Video with Additional Attributes

<video controls width="400" height="300" poster="video-thumbnail.jpg" preload="metadata"> <source src="movie.mp4" type="video/mp4"> <track src="subtitles.vtt" kind="subtitles" srclang="en" label="English"> Your browser does not support the video tag. </video>

Video Attributes

  • controls: Shows play/pause buttons
  • autoplay: Starts playing automatically (not recommended)
  • loop: Repeats the video
  • muted: Starts muted (required for autoplay in most browsers)
  • poster: Image shown before video plays
  • preload: How much to load initially (none, metadata, auto)

🎵 Audio Elements

<audio controls> <source src="song.mp3" type="audio/mpeg"> <source src="song.ogg" type="audio/ogg"> Your browser does not support the audio tag. </audio>

Audio with Attributes

<audio controls loop preload="none"> <source src="background-music.mp3" type="audio/mpeg"> <source src="background-music.wav" type="audio/wav"> Your browser does not support the audio element. </audio>

🌐 Embedding Content

YouTube Videos

<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" title="Video title" frameborder="0" allowfullscreen> </iframe>

Google Maps

<iframe src="https://www.google.com/maps/embed?pb=..." width="400" height="300" style="border:0;" allowfullscreen="" loading="lazy"> </iframe>

🏋️ Exercise 4: Creating a Photo Gallery

Create a photo gallery page with the following:

  1. Create a folder structure:
    • Create an "images" folder
    • Find 4-6 images online (or use placeholder services)
    • Save them in your images folder
  2. Create gallery.html with:
    • A main heading "My Photo Gallery"
    • At least 4 images with descriptive alt text
    • Use the figure and figcaption elements
    • One image should be a link to a larger version
  3. Add responsive CSS:
    • Make images responsive (max-width: 100%)
    • Arrange images in a grid layout
  4. Bonus: Add a video or audio element

Placeholder services you can use:

  • https://picsum.photos/400/300 (random photos)
  • https://via.placeholder.com/400x300 (colored placeholders)
  • https://placekitten.com/400/300 (cats!)

⚡ Performance Best Practices

Optimize Image Sizes

  • Use appropriate dimensions: Don't use a 2000px image for a 200px display
  • Compress images: Use tools like TinyPNG or ImageOptim
  • Choose the right format: JPEG for photos, PNG for graphics
  • Consider WebP: Modern format with excellent compression

Lazy Loading

<img src="image.jpg" alt="Description" loading="lazy">

Image Optimization Checklist

  • ☐ Always include alt text
  • ☐ Use appropriate file formats
  • ☐ Optimize file sizes
  • ☐ Provide multiple sizes for responsive design
  • ☐ Use lazy loading for images below the fold
  • ☐ Include width and height attributes to prevent layout shift

🐛 Common Mistakes

  • Missing alt text: Always provide descriptive alt text
  • Using images for text: Use actual text when possible
  • Not optimizing file sizes: Large images slow down your site
  • Hotlinking images: Don't link directly to images on other sites
  • Autoplay videos with sound: Most browsers block this anyway
