🧠 What is Semantic HTML?

Semantic HTML uses elements that clearly describe their meaning and purpose, both to developers and browsers. Instead of just using generic <div> and <span> elements, semantic HTML uses specific elements that convey meaning.

Benefits of Semantic HTML:
• Better accessibility for screen readers
• Improved SEO (search engines understand your content better)
• Cleaner, more maintainable code
• Better browser compatibility
• Easier styling with CSS

🏗️ Page Structure Elements

Basic Page Layout

<!DOCTYPE html> <html lang="en"> <head> <title>My Website</title> </head> <body> <header> <h1>My Website</h1> <nav> <ul> <li><a href="/">Home</a></li> <li><a href="/about">About</a></li> <li><a href="/contact">Contact</a></li> </ul> </nav> </header> <main> <article> <h2>Article Title</h2> <p>Article content goes here...</p> </article> </main> <aside> <h3>Related Links</h3> <ul> <li><a href="#">Link 1</a></li> <li><a href="#">Link 2</a></li> </ul> </aside> <footer> <p>&copy; 2024 My Website. All rights reserved.</p> </footer> </body> </html>
<header> - Site header with logo and navigation
<main> - Primary content area
<article> - Self-contained content
<aside> - Sidebar content
<footer> - Site footer

📋 Semantic Elements Reference

<header>

Contains introductory content, typically site branding, navigation, or article headers.

<header> <img src="logo.png" alt="Company Logo"> <h1>Welcome to Our Website</h1> <nav> <!-- Navigation menu --> </nav> </header> <!-- Headers can also be used in articles --> <article> <header> <h2>Article Title</h2> <p>By John Doe | Published March 15, 2024</p> </header> <p>Article content...</p> </article>

<nav>

Contains navigation links to other pages or sections.

<nav aria-label="Main Navigation"> <ul> <li><a href="/" aria-current="page">Home</a></li> <li><a href="/products">Products</a></li> <li><a href="/about">About</a></li> <li><a href="/contact">Contact</a></li> </ul> </nav> <!-- Breadcrumb navigation --> <nav aria-label="Breadcrumb"> <ol> <li><a href="/">Home</a></li> <li><a href="/products">Products</a></li> <li>Laptops</li> </ol> </nav>

<main>

Contains the primary content of the page. There should only be one <main> element per page.

<main> <h1>Welcome to Our Blog</h1> <p>Here you'll find our latest articles and insights.</p> <article> <!-- Blog post content --> </article> <article> <!-- Another blog post --> </article> </main>

<article>

Contains self-contained content that could be distributed independently.

<article> <header> <h2>Getting Started with HTML</h2> <p><time datetime="2024-03-15">March 15, 2024</time> by Jane Smith</p> </header> <p>HTML is the foundation of web development...</p> <section> <h3>What You'll Learn</h3> <ul> <li>Basic HTML structure</li> <li>Common elements</li> </ul> </section> <footer> <p>Tags: <a href="/tag/html">HTML</a>, <a href="/tag/beginner">Beginner</a></p> </footer> </article>

<section>

Groups related content together, typically with a heading.

<main> <section> <h2>Our Services</h2> <p>We offer a wide range of web development services.</p> <section> <h3>Frontend Development</h3> <p>HTML, CSS, and JavaScript development.</p> </section> <section> <h3>Backend Development</h3> <p>Server-side programming and databases.</p> </section> </section> </main>

<aside>

Contains content related to the main content but not essential to understanding it.

<main> <article> <h2>Climate Change Effects</h2> <p>Climate change is affecting our planet in various ways...</p> </article> <aside> <h3>Did You Know?</h3> <p>The Earth's temperature has risen by 1.1°C since 1880.</p> <h3>Related Articles</h3> <ul> <li><a href="/renewable-energy">Renewable Energy Solutions</a></li> <li><a href="/carbon-footprint">Reducing Your Carbon Footprint</a></li> </ul> </aside> </main>

<footer>

Contains footer information for the page or section.

<!-- Page footer --> <footer> <div> <h3>Contact Us</h3> <p>Email: contact@example.com</p> <p>Phone: (555) 123-4567</p> </div> <div> <h3>Follow Us</h3> <a href="/facebook">Facebook</a> | <a href="/twitter">Twitter</a> | <a href="/linkedin">LinkedIn</a> </div> <p>&copy; 2024 Example Company. All rights reserved.</p> </footer> <!-- Article footer --> <article> <h2>Article Title</h2> <p>Article content...</p> <footer> <p>Published by John Doe on <time datetime="2024-03-15">March 15, 2024</time></p> <p>Category: <a href="/web-development">Web Development</a></p> </footer> </article>

🎭 Content Elements

<figure> and <figcaption>

<figure> <img src="chart.png" alt="Sales growth chart"> <figcaption> Figure 1: Company sales have increased by 25% this quarter </figcaption> </figure> <figure> <blockquote> <p>The best way to predict the future is to create it.</p> </blockquote> <figcaption> — Peter Drucker, <cite>Management Consultant</cite> </figcaption> </figure>

<details> and <summary>

<details> <summary>What is HTML?</summary> <p>HTML (HyperText Markup Language) is the standard markup language for creating web pages. What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes the structure of a web page using elements and tags.

♿ Accessibility Benefits

How Semantic HTML Helps Accessibility:
• Screen readers can navigate by headings, landmarks, and regions
• <nav> elements create navigation landmarks
• <main> helps users skip to primary content
• <article> and <section> create logical content structure
• Semantic elements provide context to assistive technologies

ARIA Landmarks vs Semantic Elements

<!-- Instead of this: --> <div role="navigation"> <ul>...</ul> </div> <!-- Use this: --> <nav> <ul>...</ul> </nav> <!-- Instead of this: --> <div role="main"> <h1>Content</h1> </div> <!-- Use this: --> <main> <h1>Content</h1> </main>

🏋️ Exercise 7: Semantic Blog Layout

Create a semantic blog layout with the following structure:

Requirements:

  1. Create blog.html with proper semantic structure:
    • Site header with logo and navigation
    • Main content area with 2-3 blog articles
    • Sidebar with related links and author info
    • Site footer with contact info and social links
  2. Each article should include:
    • Article header with title, author, and publish date
    • Article content with sections
    • Article footer with tags and categories
    • Use the <time> element for dates
  3. Add interactive elements:
    • Use <details> for a FAQ section
    • Use <figure> and <figcaption> for images
    • Use <mark> to highlight important text
  4. Ensure accessibility:
    • Proper heading hierarchy (h1, h2, h3, etc.)
    • Descriptive navigation labels
    • Only one <main> element per page

🆚 Semantic vs Generic Elements

Instead of Use When
<div class="header"> <header> Page or section header
<div class="nav"> <nav> Navigation links
<div class="main"> <main> Primary page content
<div class="article"> <article> Self-contained content
<div class="sidebar"> <aside> Sidebar or related content
<div class="footer"> <footer> Page or section footer

🔍 SEO Benefits

Search engines use semantic HTML to better understand your content:

  • <h1>-<h6>: Create content hierarchy
  • <article>: Identifies main content pieces
  • <nav>: Helps understand site structure
  • <time>: Provides temporal context
  • <address>: Identifies contact information

🐛 Common Mistakes

  • Multiple <main> elements: Use only one per page
  • Using <section> without headings: Sections should have headings
  • Overusing <article>: Only for self-contained content
  • Nesting <header> in <header>: Don't nest landmark elements
  • Using semantic elements just for styling: Use them for meaning, not appearance
