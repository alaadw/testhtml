Lesson 10: Final Project - Complete Website

🎯 Project Overview

Congratulations! You've learned all the fundamentals of HTML and CSS. Now it's time to put everything together and build a complete, professional website from scratch.

🚀 Your Mission

Build a responsive personal portfolio website that showcases everything you've learned. This will be a real website you can use to showcase your skills!

📋 Project Requirements

✅ Must-Have Features

  • ☐ Responsive design (mobile, tablet, desktop)
  • ☐ Semantic HTML structure
  • ☐ Clean, professional CSS styling
  • ☐ At least 3 pages (Home, About, Contact)
  • ☐ Working navigation between pages
  • ☐ Contact form with validation
  • ☐ Image gallery or portfolio section
  • ☐ Accessibility features

🗂️ Recommended File Structure

my-portfolio/ ├── index.html ├── about.html ├── contact.html ├── portfolio.html ├── css/ │ ├── styles.css │ └── responsive.css ├── images/ │ ├── profile.jpg │ ├── project1.jpg │ ├── project2.jpg │ └── background.jpg ├── js/ │ └── script.js (optional) └── README.md

📄 Page-by-Page Breakdown

🏠 Homepage (index.html)

Required Elements:

  • Header: Logo/name and navigation menu
  • Hero Section: Eye-catching intro with your photo and tagline
  • Skills Section: Your technical skills with visual indicators
  • Featured Projects: 2-3 of your best projects with images
  • Call-to-Action: Link to contact page or portfolio
  • Footer: Social links and copyright

HTML Structure Example:

All rights reserved.</p> <div class="social-links"> <a href="#">LinkedIn</a> <a href="#">GitHub</a> <a href="#">Twitter</a> </div> </footer> </body> </html>

👤 About Page (about.html)

Required Elements:

  • Personal Story: Your background and journey
  • Skills & Experience: Detailed list of technical skills
  • Education & Certifications: Your learning background
  • Interests: What you're passionate about
  • Resume Download: Link to your resume PDF

Content Ideas:

  • Why you chose web development
  • Your favorite programming languages
  • Hobbies and interests outside of coding
  • Career goals and aspirations
  • Fun facts about yourself

📁 Portfolio Page (portfolio.html)

Required Elements:

  • Project Gallery: Grid layout of all your projects
  • Filter Options: Categories like "Web Apps", "Designs", etc.
  • Project Details: Technology used, challenges, solutions
  • Live Demo Links: Link to working versions
  • Source Code Links: Link to GitHub repositories

Project Ideas to Include:

  • This HTML tutorial website
  • Personal blog or landing page
  • Calculator or other interactive tool
  • Photo gallery with filtering
  • Restaurant menu or business website

📧 Contact Page (contact.html)

Required Elements:

  • Contact Form: Name, email, subject, message
  • Contact Information: Email, phone, location
  • Social Media Links: Professional social profiles
  • Map: Embedded map of your location (optional)
  • Response Time: When they can expect to hear back

Form HTML Example:

<form class="contact-form" action="#" method="post"> <fieldset> <legend>Send me a message</legend> <label for="name">Name *</label> <input type="text" id="name" name="name" required minlength="2"> <label for="email">Email *</label> <input type="email" id="email" name="email" required> <label for="subject">Subject</label> <select id="subject" name="subject"> <option value="general">General Inquiry</option> <option value="project">Project Discussion</option> <option value="collaboration">Collaboration</option> </select> <label for="message">Message *</label> <textarea id="message" name="message" rows="6" required minlength="10"></textarea> <button type="submit">Send Message</button> </fieldset> </form>

🎨 CSS Styling Guide

Color Scheme Selection

/* Professional Color Palette Example */ :root { --primary-color: #2c3e50; --secondary-color: #3498db; --accent-color: #e74c3c; --text-color: #333333; --light-gray: #f8f9fa; --dark-gray: #6c757d; --white: #ffffff; } /* Apply colors throughout your site */ body { color: var(--text-color); background-color: var(--white); } .btn-primary { background-color: var(--primary-color); color: var(--white); } .btn-secondary { background-color: var(--secondary-color); color: var(--white); }

Typography System

/* Import Google Fonts */ @import url('https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;600;700&display=swap'); /* Typography Scale */ body { font-family: 'Poppins', sans-serif; font-size: 16px; line-height: 1.6; } h1 { font-size: 2.5rem; font-weight: 700; } h2 { font-size: 2rem; font-weight: 600; } h3 { font-size: 1.5rem; font-weight: 600; } h4 { font-size: 1.25rem; font-weight: 500; } .lead { font-size: 1.125rem; font-weight: 300; } .small { font-size: 0.875rem; }

Responsive Layout

/* Mobile-first CSS Grid Layout */ .container { display: grid; grid-template-columns: 1fr; gap: 2rem; max-width: 1200px; margin: 0 auto; padding: 0 1rem; } /* Tablet */ @media (min-width: 768px) { .container { grid-template-columns: repeat(2, 1fr); padding: 0 2rem; } } /* Desktop */ @media (min-width: 1024px) { .container { grid-template-columns: repeat(3, 1fr); padding: 0 3rem; } } /* Navigation responsive */ .nav-links { display: none; } @media (min-width: 768px) { .nav-links { display: flex; gap: 2rem; } }

♿ Accessibility Checklist

Ensure Your Site Is Accessible:

  • ☐ All images have descriptive alt text
  • ☐ Color contrast meets WCAG guidelines
  • ☐ Forms have proper labels and validation messages
  • ☐ Navigation is keyboard accessible
  • ☐ Focus indicators are visible
  • ☐ Heading hierarchy is logical (h1, h2, h3...)
  • ☐ Links have descriptive text (not "click here")
  • ☐ Page has a proper title and meta description

🚀 Deployment Options

Free Hosting Platforms

GitHub Pages (Recommended)

  1. Create a GitHub repository named "your-username.github.io"
  2. Upload your website files
  3. Enable GitHub Pages in repository settings
  4. Your site will be live at https://your-username.github.io

Other Options:

  • Netlify: Drag and drop deployment
  • Vercel: Great for static sites
  • Surge.sh: Simple command-line deployment
  • Firebase Hosting: Google's hosting platform

📝 Project Phases

Phase 1: Planning & Setup (Day 1)

  1. Create your project folder structure
  2. Plan your content and gather assets (photos, text)
  3. Choose your color scheme and fonts
  4. Create wireframes for each page
  5. Set up your HTML files with basic structure

Phase 2: HTML Structure (Day 2)

  1. Build the HTML structure for all pages
  2. Add all content (text, images, forms)
  3. Ensure semantic HTML is used throughout
  4. Test navigation between pages
  5. Validate your HTML code

Phase 3: CSS Styling (Day 3-4)

  1. Create your CSS reset and base styles
  2. Style the navigation and header
  3. Design the hero section and main content areas
  4. Style forms, buttons, and interactive elements
  5. Add visual effects (shadows, gradients, transitions)

Phase 4: Responsive Design (Day 5)

  1. Test your site on different screen sizes
  2. Add media queries for tablet and mobile
  3. Optimize images for different devices
  4. Test navigation on mobile devices
  5. Ensure forms work well on all devices

Phase 5: Testing & Deployment (Day 6)

  1. Test all links and forms
  2. Check accessibility with screen reader
  3. Validate HTML and CSS code
  4. Optimize images and file sizes
  5. Deploy to your chosen hosting platform
