Lesson 1: HTML Basics and Document Structure

🎯 What You'll Learn

  • What is HTML and how it works
  • Basic HTML document structure

  • How to create your first web page

📖 What is HTML?

HTML stands for HyperText Markup Language. It's the standard language used to create web pages. HTML uses "tags" to define different parts of a web page, like headings, paragraphs, links, and images.

Think of HTML like the skeleton of a house:
- HTML provides the basic structure
- CSS adds the styling (paint, decoration)
- JavaScript adds interactive behavior (lights, doors)

🏗️ Basic HTML Document Structure

Every HTML document follows the same basic structure:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My First Web Page</title> </head> <body> <h1>Welcome to My Website</h1> <p>This is my first paragraph!</p> </body> </html>

🔍 Breaking Down the Structure

1. <!DOCTYPE html>

This tells the browser that this is an HTML5 document. Always put this at the very top!

2. <html>

This is the root element that contains all other elements on the page.

3. <head>

Contains information about the page that isn't displayed on the page itself:

  • <meta charset="UTF-8"> - Tells the browser how to interpret characters
  • <meta name="viewport"...> - Makes the page mobile-friendly
  • <title> - Sets the title that appears in the browser tab

4. <body>

Contains all the content that visitors will see on your web page.

📝 Understanding HTML Tags

HTML tags are keywords surrounded by angle brackets: <tagname>

Key Points about Tags:
• Most tags come in pairs: opening tag <h1> and closing tag </h1>
• The closing tag has a forward slash: </tagname>
• Content goes between the opening and closing tags
• Some tags are self-closing: <br> or <img>

🎨 Your First HTML Elements

Headings

HTML has 6 levels of headings, from most important (h1) to least important (h6):

<h1>Main Title (Biggest)</h1> <h2>Section Title</h2> <h3>Subsection Title</h3> <h4>Minor Heading</h4> <h5>Small Heading</h5> <h6>Smallest Heading</h6>

Paragraphs

<p>This is a paragraph of text. It can contain multiple sentences and will automatically wrap to the next line when needed.</p>

🏋️ Exercise 1: Create Your First HTML Page

  1. Open a text editor (Notepad, VS Code, etc.)
  2. Copy the basic HTML structure from above
  3. Change the title to "My First Web Page"
  4. Add an h1 heading with your name
  5. Add a paragraph introducing yourself
  6. Save the file as "my-first-page.html"
  7. Open the file in your web browser

Expected result: You should see your name as a big heading and your introduction as regular text below it!

🔧 Tips for Success

  • Use proper indentation - Indent nested elements to make your code readable
  • Always close your tags - Every opening tag needs a closing tag
  • Use lowercase - While HTML isn't case-sensitive, use lowercase for consistency
  • Test in a browser - Always check how your code looks in a web browser

🐛 Common Beginner Mistakes

  • Forgetting the closing tag
  • Forgetting the <!DOCTYPE html> declaration
  • Putting content outside the <body> tag
  • Nesting tags incorrectly
Remember: Don't worry about making your page look beautiful yet! In this lesson, we're just learning the basic structure. We'll add styling in later lessons.
