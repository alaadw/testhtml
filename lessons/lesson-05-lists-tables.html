📋 HTML Lists

Unordered Lists (Bullet Points)

Use <ul> for lists where order doesn't matter:

<ul> <li>Apples</li> <li>Bananas</li> <li>Oranges</li> <li>Grapes</li> </ul>
  • Apples
  • Bananas
  • Oranges
  • Grapes

Ordered Lists (Numbered)

Use <ol> for lists where order is important:

<ol> <li>Preheat oven to 350°F</li> <li>Mix dry ingredients</li> <li>Add wet ingredients</li> <li>Bake for 25 minutes</li> </ol>
  1. Preheat oven to 350°F
  2. Mix dry ingredients
  3. Add wet ingredients
  4. Bake for 25 minutes

Description Lists

Use <dl> for term-definition pairs:

<dl> <dt>HTML</dt> <dd>HyperText Markup Language</dd> <dt>CSS</dt> <dd>Cascading Style Sheets</dd> <dt>JavaScript</dt> <dd>Programming language for web interactivity</dd> </dl>
HTML
HyperText Markup Language
CSS
Cascading Style Sheets
JavaScript
Programming language for web interactivity

🏗️ Nested Lists

You can put lists inside other lists:

<ul> <li>Fruits <ul> <li>Apples <ul> <li>Red Delicious</li> <li>Granny Smith</li> </ul> </li> <li>Bananas</li> <li>Oranges</li> </ul> </li> <li>Vegetables <ul> <li>Carrots</li> <li>Broccoli</li> </ul> </li> </ul>
  • Fruits
    • Apples
      • Red Delicious
      • Granny Smith
    • Bananas
    • Oranges
  • Vegetables
    • Carrots
    • Broccoli

🎨 List Styling Options

Ordered List Types

<!-- Numbers (default) --> <ol type="1"> <li>First item</li> <li>Second item</li> </ol> <!-- Letters --> <ol type="A"> <li>First item</li> <li>Second item</li> </ol> <!-- Roman numerals --> <ol type="I"> <li>First item</li> <li>Second item</li> </ol> <!-- Start from specific number --> <ol start="5"> <li>Fifth item</li> <li>Sixth item</li> </ol>

Numbers:

  1. First item
  2. Second item

Letters:

  1. First item
  2. Second item

Roman numerals:

  1. First item
  2. Second item

Starting from 5:

  1. Fifth item
  2. Sixth item

📊 HTML Tables

Basic Table Structure

<table> <tr> <th>Name</th> <th>Age</th> <th>City</th> </tr> <tr> <td>John</td> <td>25</td> <td>New York</td> </tr> <tr> <td>Sarah</td> <td>30</td> <td>London</td> </tr> </table>
Name Age City
John 25 New York
Sarah 30 London
Table Elements:
• <table> = Contains the entire table
• <tr> = Table row
• <th> = Table header cell
• <td> = Table data cell

Semantic Table Structure

<table> <thead> <tr> <th>Product</th> <th>Price</th> <th>Stock</th> </tr> </thead> <tbody> <tr> <td>Laptop</td> <td>$999</td> <td>15</td> </tr> <tr> <td>Mouse</td> <td>$25</td> <td>50</td> </tr> </tbody> <tfoot> <tr> <th>Total</th> <td>$1,024</td> <td>65</td> </tr> </tfoot> </table>
Product Price Stock
Laptop $999 15
Mouse $25 50
Total $1,024 65

🔗 Spanning Cells

Column Span (colspan)

<table> <tr> <th colspan="3">Sales Report</th> </tr> <tr> <th>Month</th> <th>Revenue</th> <th>Growth</th> </tr> <tr> <td>January</td> <td>$10,000</td> <td>5%</td> </tr> </table>
Sales Report
Month Revenue Growth
January $10,000 5%

Row Span (rowspan)

<table> <tr> <th>Department</th> <th>Employee</th> <th>Role</th> </tr> <tr> <td rowspan="2">Engineering</td> <td>Alice</td> <td>Senior Developer</td> </tr> <tr> <td>Bob</td> <td>Junior Developer</td> </tr> </table>
Department Employee Role
Engineering Alice Senior Developer
Bob Junior Developer

♿ Table Accessibility

Table Caption

<table> <caption>Monthly Sales Data for Q1 2024</caption> <thead> <tr> <th>Month</th> <th>Sales</th> </tr> </thead> <tbody> <tr> <td>January</td> <td>$15,000</td> </tr> </tbody> </table>

Header Scope

<table> <tr> <th scope="col">Name</th> <th scope="col">Math</th> <th scope="col">Science</th> </tr> <tr> <th scope="row">Alice</th> <td>85</td> <td>92</td> </tr> </table>

🏋️ Exercise 5: Creating a Restaurant Menu

Create a restaurant menu page using lists and tables:

Part 1: Menu Categories (Lists)

  1. Create "menu.html"
  2. Use an unordered list for main categories (Appetizers, Main Courses, Desserts)
  3. For each category, create a nested ordered list with dishes
  4. Use a description list for dietary information (Vegetarian, Gluten-Free, etc.)

Part 2: Nutritional Information (Table)

  1. Create a table showing nutritional information for popular dishes
  2. Include columns: Dish Name, Calories, Protein, Carbs, Fat
  3. Use proper table structure with thead, tbody, and tfoot
  4. Add a caption and appropriate scope attributes
  5. Use colspan for category headers

Part 3: Styling (Optional CSS)

  1. Add borders to your table
  2. Style your lists with custom bullet points
  3. Make the table responsive

🎨 Basic Table Styling

<style> table { border-collapse: collapse; width: 100%; } th, td { border: 1px solid #ddd; padding: 8px; text-align: left; } th { background-color: #f2f2f2; font-weight: bold; } tr:nth-child(even) { background-color: #f9f9f9; } tr:hover { background-color: #f5f5f5; } </style>

📱 Responsive Tables

<style> .table-container { overflow-x: auto; } table { min-width: 500px; } @media (max-width: 600px) { table, thead, tbody, th, td, tr { display: block; } th { position: absolute; top: -9999px; left: -9999px; } tr { border: 1px solid #ccc; margin-bottom: 10px; } td { border: none; position: relative; padding-left: 50% !important; } td:before { content: attr(data-label) ": "; position: absolute; left: 6px; width: 45%; font-weight: bold; } } </style> <div class="table-container"> <table> <tr> <td data-label="Name">John</td> <td data-label="Email">john@email.com</td> <td data-label="Phone">123-456-7890</td> </tr> </table> </div>

🤔 When to Use Lists vs Tables

Use Lists When:
• Displaying a simple collection of items
• Order matters (numbered steps)
• Creating navigation menus
• Showing categories and subcategories

Use Tables When:
• Displaying tabular data (rows and columns)
• Comparing data across multiple attributes
• Showing relationships between data points
• Creating data grids or spreadsheet-like displays

🐛 Common Mistakes

  • Using tables for layout: Use CSS Grid or Flexbox instead
  • Missing table headers: Always use <th> elements
  • Forgetting table structure: Use thead, tbody, tfoot for semantic structure
  • Not considering mobile: Make tables responsive
  • Poor accessibility: Add captions and scope attributes
