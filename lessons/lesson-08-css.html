🎨 What is CSS?

CSS (Cascading Style Sheets) is used to style and layout HTML elements. While HTML provides structure, CSS provides the visual presentation.

CSS Controls:
• Colors and backgrounds
• Fonts and text styling
• Spacing and layout
• Borders and shadows
• Animations and transitions
• Responsive design

📝 Three Ways to Add CSS

1. Inline CSS

<h1 style="color: red; font-size: 24px;">Red Heading</h1> <p style="background-color: yellow; padding: 10px;">Yellow paragraph</p>

Red Heading

Yellow paragraph

2. Internal CSS

<head> <style> h1 { color: blue; font-size: 28px; } p { background-color: lightgray; padding: 15px; border-radius: 5px; } </style> </head>

3. External CSS

<!-- In HTML file --> <head> <link rel="stylesheet" href="styles.css"> </head> /* In styles.css file */ h1 { color: green; font-size: 32px; } p { line-height: 1.6; margin-bottom: 20px; }
Best Practice: Use external CSS files for better organization, performance, and maintainability. Inline CSS should be used sparingly.

🎯 CSS Selectors

Basic Selectors

/* Element selector */ h1 { color: blue; } /* Class selector */ .highlight { background-color: yellow; } /* ID selector */ #main-title { font-size: 36px; } /* Multiple selectors */ h1, h2, h3 { font-family: Arial, sans-serif; }
<!-- HTML using the selectors above --> <h1 id="main-title">Main Title</h1> <h2>Subtitle</h2> <p class="highlight">This paragraph is highlighted</p> <p>This is a regular paragraph</p>

Advanced Selectors

/* Descendant selector */ article p { color: #333; } /* Child selector */ nav > ul { list-style: none; } /* Pseudo-classes */ a:hover { color: red; } a:visited { color: purple; } /* Pseudo-elements */ p::first-line { font-weight: bold; } /* Attribute selector */ input[type="email"] { border: 2px solid blue; }

🌈 Colors and Backgrounds

Color Values

/* Named colors */ color: red; color: blue; color: forestgreen; /* Hex colors */ color: #ff0000; /* Red */ color: #00ff00; /* Green */ color: #0000ff; /* Blue */ /* RGB colors */ color: rgb(255, 0, 0); /* Red */ color: rgba(255, 0, 0, 0.5); /* Semi-transparent red */ /* HSL colors */ color: hsl(0, 100%, 50%); /* Red */ color: hsla(0, 100%, 50%, 0.5); /* Semi-transparent red */

Background Properties

/* Background color */ background-color: #f0f0f0; /* Background image */ background-image: url('pattern.png'); /* Background properties combined */ background: #f0f0f0 url('image.jpg') no-repeat center center; background-size: cover; /* Gradient backgrounds */ background: linear-gradient(to right, #ff7e5f, #feb47b); background: radial-gradient(circle, #ff7e5f, #feb47b);

📦 The CSS Box Model

Every HTML element is essentially a rectangular box consisting of:

/* Box model properties */ .box { width: 300px; height: 200px; padding: 20px; /* Space inside the element */ border: 2px solid black; /* Border around the element */ margin: 15px; /* Space outside the element */ } /* Box-sizing property */ .box-sizing-border { box-sizing: border-box; /* Width includes padding and border */ }

Spacing Properties

/* Margin (outside spacing) */ margin: 10px; /* All sides */ margin: 10px 20px; /* Top/bottom, Left/right */ margin: 10px 15px 20px 25px; /* Top, Right, Bottom, Left */ margin-top: 10px; margin-right: 15px; margin-bottom: 20px; margin-left: 25px; /* Padding (inside spacing) */ padding: 15px; /* All sides */ padding: 10px 20px; /* Top/bottom, Left/right */ padding: 5px 10px 15px 20px; /* Top, Right, Bottom, Left */ padding-top: 5px; /* Border */ border: 1px solid black; border-width: 2px; border-style: solid; border-color: red; border-radius: 10px; /* Rounded corners */

📱 Responsive Design Basics

Media Queries

/* Mobile-first approach */ .container { width: 100%; padding: 10px; } /* Tablet styles */ @media (min-width: 768px) { .container { width: 750px; margin: 0 auto; padding: 20px; } } /* Desktop styles */ @media (min-width: 1024px) { .container { width: 1000px; padding: 30px; } } /* High-resolution displays */ @media (min-resolution: 2dppx) { .logo { background-image: url('logo@2x.png'); background-size: 100px 50px; } }

Responsive Units

/* Relative units */ width: 50%; /* Percentage of parent */ font-size: 1.2em; /* Relative to parent font size */ font-size: 1.5rem; /* Relative to root font size */ width: 50vw; /* 50% of viewport width */ height: 100vh; /* 100% of viewport height */ /* Absolute units */ width: 300px; /* Pixels */ font-size: 14pt; /* Points */

🎛️ Basic Layout

Display Property

/* Block elements (full width) */ display: block; /* Inline elements (content width) */ display: inline; /* Inline-block (best of both) */ display: inline-block; /* Hide elements */ display: none; visibility: hidden; /* Takes up space but invisible */

Flexbox (Simple Layout)

.flex-container { display: flex; justify-content: space-between; /* Horizontal alignment */ align-items: center; /* Vertical alignment */ gap: 20px; /* Space between items */ } .flex-item { flex: 1; /* Equal width items */ }

🏋️ Exercise 8: Style Your Portfolio

Create a styled personal portfolio page:

Step 1: Create the HTML structure

  1. Create "portfolio.html" with semantic HTML
  2. Include: header, nav, main, sections for about/skills/projects, footer
  3. Add placeholder content for each section

Step 2: Create the CSS styling

  1. Create "styles.css" and link it to your HTML
  2. Style the layout with a color scheme of your choice
  3. Use Google Fonts for typography
  4. Add hover effects to navigation and buttons

Step 3: Make it responsive

  1. Add media queries for mobile and tablet
  2. Use flexbox or grid for layout
  3. Ensure text is readable on all screen sizes

Required CSS techniques:

  • Custom color scheme and typography
  • Box shadows and border radius
  • Hover effects and transitions
  • Responsive design with media queries
  • Flexbox or CSS Grid layout

🐛 Common CSS Mistakes

  • Not using a CSS reset: Different browsers have different default styles
  • Overly specific selectors: Keep selectors simple and reusable
  • Not organizing CSS: Group related styles together
  • Ignoring mobile design: Always design mobile-first
  • Using too many colors/fonts: Stick to a consistent design system
  • Not testing across browsers: Check compatibility
