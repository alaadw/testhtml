📝 Basic Text Formatting Elements

Bold and Strong Text

There are two ways to make text bold in HTML:

<b>This text is bold</b> <strong>This text is strong (also appears bold)</strong>
This text is bold
This text is strong (also appears bold)
What's the difference?
• <b> is just for visual styling (makes text look bold)
• <strong> indicates important content (screen readers will emphasize it)

Italic and Emphasis

Similarly, there are two ways to make text italic:

<i>This text is italic</i> <em>This text is emphasized (also appears italic)</em>
This text is italic
This text is emphasized (also appears italic)

🔧 Container Elements

Div Elements (Block-level)

The <div> element is used to group other elements together:

<div> <h2>Section Title</h2> <p>This paragraph is inside a div.</p> <p>So is this one.</p> </div>

Span Elements (Inline)

The <span> element is used to group inline content:

<p>This is a paragraph with <span>some text in a span</span> element.</p>

📱 Semantic vs Presentational Elements

Best Practice: Choose elements based on meaning, not appearance!
• Use <strong> for important content, not just to make text bold
• Use <em> for emphasized content, not just to make text italic
• This makes your content more accessible and SEO-friendly

🎨 Combining Elements

You can combine multiple formatting elements:

<p>This is <strong><em>very important and emphasized</em></strong> text.</p> <p>Chemical formula: H<sub>2</sub>SO<sub>4</sub></p> <p>Math equation: (a+b)<sup>2</sup> = a<sup>2</sup> + 2ab + b<sup>2</sup></p>

This is very important and emphasized text.

🐛 Common Mistakes

  • Overlapping tags: <strong><em>text</strong></em> ❌ (Wrong!)
  • Correct nesting: <strong><em>text</em></strong> ✅
  • Using <br> for spacing: Use CSS margins instead
  • Overusing <b> and <i>: Prefer <strong> and <em>
