Lesson 3: Links and Navigation

🎯 What You'll Learn

  • How to create links to other websites
  • Linking to other pages on your website
  • Creating internal page navigation with anchors
  • Email and phone links
  • Download links
  • Link attributes and best practices

🔗 Basic Link Syntax

Links are created using the <a> (anchor) element with the href attribute:

<a href="https://www.google.com">Visit Google</a>
Visit Google
Anatomy of a Link:
• <a> = anchor element
• href = hypertext reference (where the link goes)
• Text between tags = what the user sees and clicks on

🌐 Types of Links

1. External Links (to other websites)

<a href="https://www.wikipedia.org">Wikipedia</a> <a href="https://www.github.com">GitHub</a> <a href="https://developer.mozilla.org">MDN Web Docs</a>
Wikipedia
GitHub
MDN Web Docs

2. Internal Links (to other pages on your site)

<a href="about.html">About Us</a> <a href="contact.html">Contact</a> <a href="../index.html">Home</a>
About Us
Contact
Home

3. Anchor Links (to sections on the same page)

<!-- Create an anchor --> <h2 id="section1">Section 1</h2> <!-- Link to the anchor --> <a href="#section1">Go to Section 1</a> <a href="#top">Back to top</a>
Go to Section 1
Back to top

📧 Special Types of Links

Email Links

<a href="mailto:someone@example.com">Send Email</a> <a href="mailto:help@company.com?subject=Help Request&body=Hello, I need help with...">Email with Subject</a>
Send Email
Email with Subject

Phone Links

<a href="tel:+1234567890">Call us: (123) 456-7890</a>
Call us: (123) 456-7890

Download Links

<a href="document.pdf" download>Download PDF</a> <a href="image.jpg" download="my-image.jpg">Download Image</a>

🎛️ Link Attributes

Target Attribute

Controls where the link opens:

<!-- Opens in same window/tab (default) --> <a href="https://www.example.com">Same Window</a> <!-- Opens in new tab/window --> <a href="https://www.example.com" target="_blank">New Tab</a> <!-- Opens in parent frame (for frames) --> <a href="page.html" target="_parent">Parent Frame</a> <!-- Opens in top-level window --> <a href="page.html" target="_top">Top Window</a>
Security Note: When using target="_blank", add rel="noopener noreferrer" for security:
<a href="https://external-site.com" target="_blank" rel="noopener noreferrer">External Link</a>

Title Attribute

<a href="https://www.example.com" title="Visit Example.com for more information">Example Site</a>
Example Site (hover to see tooltip)

🧭 Creating Navigation Menus

<nav> <ul> <li><a href="index.html">Home</a></li> <li><a href="about.html">About</a></li> <li><a href="services.html">Services</a></li> <li><a href="contact.html">Contact</a></li> </ul> </nav>
  • Home
  • About
  • Services
  • Contact

📍 Breadcrumb Navigation

<nav aria-label="breadcrumb"> <ol> <li><a href="/">Home</a></li> <li><a href="/products">Products</a></li> <li><a href="/products/laptops">Laptops</a></li> <li>MacBook Pro</li> </ol> </nav>

🎨 Styling Link States with CSS

You can style different link states (we'll learn more about CSS later):

<style> a:link { color: blue; } /* unvisited link */ a:visited { color: purple; } /* visited link */ a:hover { color: red; } /* mouse over link */ a:active { color: yellow; } /* selected link */ </style>

🏋️ Exercise 3: Building a Simple Website

Create a small website with multiple pages:

  1. Create index.html (home page) with:
    • A welcome heading
    • Navigation menu linking to all pages
    • A paragraph about the website
  2. Create about.html with:
    • Information about yourself or a fictional company
    • Navigation back to home
    • An email link
  3. Create contact.html with:
    • Contact information
    • Phone number as clickable link
    • Email link with pre-filled subject
    • Link to external map service
  4. Add anchor links within one page to jump between sections

Test: Make sure all links work and you can navigate between all pages!

🛣️ File Path Understanding

Relative Paths

<!-- Same folder --> <a href="page2.html">Page 2</a> <!-- Subfolder --> <a href="images/photo.html">Photo Page</a> <!-- Parent folder --> <a href="../index.html">Back to Home</a> <!-- Two levels up --> <a href="../../home.html">Home</a>

Absolute Paths

<!-- From root of website --> <a href="/index.html">Home</a> <a href="/about/team.html">Team Page</a> <!-- Full URL --> <a href="https://www.mysite.com/page.html">Full URL</a>

♿ Accessibility Best Practices

  • Use descriptive link text: "Read our privacy policy" instead of "Click here"
  • Indicate external links: Let users know when links leave your site
  • Use focus indicators: Make sure links are keyboard accessible
  • Provide context: Use title attributes for additional information
<!-- Good link text --> <a href="privacy.html">Read our privacy policy</a> <!-- Bad link text --> <a href="privacy.html">Click here</a>

🐛 Common Link Mistakes

  • Missing protocol: Use https:// for external links
  • Broken file paths: Check your folder structure
  • Forgetting closing tags: Always close </a>
  • Generic link text: Avoid "click here" or "read more"
  • Security issues: Use rel="noopener" with target="_blank"
